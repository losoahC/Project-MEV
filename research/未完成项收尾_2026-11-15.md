## 1. Exploiter 1 = 0x7c8601d4645b93cea45f71e118a729332e6b5ca0

三条独立证据一致：

- **实时标签**：2026-11-13 在浏览器中打开 Etherscan 地址页，标签为 “Binance Hot Wallet Exploiter”（无编号），资金来源显示 Tornado.Cash 0.1 ETH。2–16 号在快照中均为带编号标签。
- **时间顺序**：该地址首次活动在区块 26295416，比其余 15 个钱包中最早的一个还早 5,378 个区块。
- **链上控制权**：区块 26300753，该地址向 Binance 热钱包 `0x28c6c06298d514db089934071355e5743bf21d60` 发送 EIP-7702（type 4）交易。热钱包在 26300752 没有代码，从 26300753 起带有指向 `0x63e842b054bd624a465454d533c33f573e9c6fae` 的委托代码，截止区块时已恢复为空。之后 1 号钱包调用热钱包，把 63 种代币转入 Exploiter 2，另把 122 种代币转入 `0xa97bf7836f8a08f9ed91d41453d371493fae8d10`。

结论：1 号是触发热钱包外流的操作地址，与未编号标签是同一地址。剩余说明：“1” 是老师清单对未编号标签的编号，Etherscan 本身不显示数字 1。

## 2. 八块跨区块闭环的因果实验

对象是 E53 两腿闭环：区块 26302729 买入，26302735 卖出，机器人钱包 `0x3d63…22a1`，实际净现金流 0.007843240319553997 ETH。

- **基准**：从历史父区块 26302727 连续模拟 8 个区块（含 withdrawals 与历史区块哈希），在退出腿处截止。全部 1,851 笔交易的状态、gas 和日志与链上收据完全一致。
- **干预**：把黑客交易替换为同 nonce、21000 gas 的零值自转账，保证该发送者之后的 nonce 仍然有效。若第三方交易因资金链变化而无法支付 gas，只替换那一笔，并在结果中逐笔列出。

| 场景 | 机器人买/卖腿 | 机器人净额 ETH | 与实际之差 ETH |
|---|---|---:|---:|
| 实际（基准复现） | 成功 / 成功 | 0.007843 | 0 |
| 去掉目标 1（26302728） | 回滚 / 回滚 | −0.000295 | 0.008138 |
| 去掉目标 2（26302732） | 成功 / 成功 | 0.010956 | −0.003112 |
| 去掉两笔目标 | 回滚 / 回滚 | −0.000295 | 0.008138 |
| 去掉窗口内全部 11 笔黑客交易 | 回滚 / 回滚 | −0.000295 | 0.008138 |

结论：该闭环因果依赖黑客在 26302728 的兑换；没有它，机器人两腿都会回滚。目标 2 反而压低了机器人收益。最干净的场景（去掉全部黑客交易）中，被替换的两笔第三方交易都不触及该池。“去掉目标 1” 场景中被替换的一笔（`0xb414f87b…`）触及该池，因此该行只作为旁证。计入 MEV 下界的数值取实际利润上限 0.007843 ETH。

## 4. 全事件 MEV 总额的上下界

估计对象：在 3,311 个区块窗口、55 地址范围内，第三方搜索者及其付费的 builder 因黑客兑换而获得的价值。各分项按交易哈希互不重叠。ETH/USD 统一按 2,243.93 换算。

| | ETH | 约 USD | 关键假设 |
|---|---:|---:|---|
| **下界** | **312.73** | **70.2 万** | 只计逐笔有干预证据的部分 |
| 其中 夹击（112 个闭合组净额） | 81.01 | | 移除目标后退出腿失败（117 次实验全部验证）；含 1 个非正组 |
| 其中 后置套利（339 笔） | 42.12 | | 实际与去目标后现金流之差，取各目标中最小值，截断在 [0, 实际利润] |
| 其中 E53 跨区块闭环 | 0.0078 | | 第 2 节 |
| 其中 builder 收入 | 189.58 | | 上述夹击腿的优先费，以及去目标后回滚或亏损的后置套利所付的优先费和直接转账 |
| **上界** | **6,687.94** | **1,500.7 万** | 把范围内所有候选都算作黑客导致 |
| 其中 全部夹击组正收益 | 142.90 | | 298 个可估值组；另 266 个组无法估值 |
| 其中 全部单笔闭环正收益 | 84.56 | | 1,063 笔，不论是否与目标同块关联 |
| 其中 全部 MEV 候选付给 builder 的费用 | 6,460.47 | | 窗口内所有候选交易，明显偏宽 |
| **硬上限** | — | **5,303.2 万** | 16 钱包严格执行差额；排序收益不可能超过黑客损失 |

如果只看搜索者自己留下的部分，区间是 **123.1–227.5 ETH（约 27.6 万–51.0 万美元）**。区间宽度主要来自 builder 一项：哪些 builder 收入由黑客引起，链上无法逐笔分离。

另有一个需要单独说明的方向：在后置套利干预中，有 61 笔“去掉黑客交易后机器人反而赚更多”。全部带符号求和为 −138.6 ETH，主要来自 4 笔大额个案。原因是黑客兑换本身抹平了已有价差，抢走了这些机器人的机会。这会减少其他机器人的收入，但不减少从黑客身上提取的价值，因此不从下界中扣除。

### 与外部估计的关系

Bitquery 公开估计交易者约 5,990 万美元、构建者/验证者约 2,950 万美元，远高于本上界的搜索者部分。主要差异来自三点：

1. 本研究只覆盖 3,311 个区块和 55 个地址。
2. 本研究不把成交差额直接算作 MEV。
3. 不能估值的 266 个夹击组没有计入。

因此，本区间是“本样本范围内”的界，不是整个事件跨链、跨期的总额。
