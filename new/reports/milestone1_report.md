# 第一阶段研究报告：数据、钱包和资金流

研究问题：黑客急迫兑换造成的价格偏离中，哪些价值由套利者取得，哪些通过拍卖流向 builder/proposer？本阶段建立原始证据和可重算样本，为后续套利及拍卖分析提供输入。

当前结果是事件窗口取证与一笔兑换的参考价差，尚未给出全事件套利利润、MEV 总额或 Binance 最终损失。

## 1. 样本与证据

Ethereum 区块 26,300,640–26,303,950；有转账事件的样本时间为 2026-10-29 20:24:23–2026-10-30 07:02:47 UTC。钱包线索来自父项目 2026-11-03 的第三方快照，151 个钱包历史分页来自原 Blockscout 缓存。本次按交易哈希选取候选交易，再用 RPC 收据和区块头核对区块哈希、交易位置、日志标识和执行成功状态。原生币转移来自完整调用树中未回滚的 CALL、CREATE 或 SELFDESTRUCT，另外保留无轨迹时可观察的顶层交易 value。

共核对 1,640 笔交易，保留 57,042 条去重边和 1,155 个 V2/V3 兼容 Swap 事件。大量未估值代币事件及潜在地址污染记录仍在数据中。它们证明相应日志存在，不证明资产有经济价值或黑客主动参与。V4 和未识别协议尚未解码，不可由本阶段事件数推断全覆盖。

每条边包含 chain、合约、原始整数数量、decimals、交易哈希、block hash、交易索引、log index 或 traceAddress、UTC 时间和原始对象路径。`edge_id` 使用 chain + transaction hash + event location，全局去重，避免两个钱包历史都返回同笔转账时重复记账。

## 3. 代表性真实兑换

[交易 0x152e…f8cc](https://etherscan.io/tx/0x152e005f6dcccd941e0a2c7156b955c6baad08a347685bcf5518776dab04f8cc)，钱包 `0x0ddf0480016e6bcb2c1f5d190d221fba1320697e`，2026-10-29 20:47:47 UTC，区块 26,300,886，索引 2。

| 项目 | 独立重算结果 |
|---|---:|
| USDT 净支付 | 10,000,000 USDT |
| ETH 净到账，不含 gas | 3,552.228717651589845452 ETH |
| gas 支出 | 0.351855780200757930 ETH |
| 前一完整分钟 USDT/USD | 0.99876 |
| 前一完整分钟 ETH/USD | 2,248.40 |
| 输入参考价值 | $9,987,600.00 |
| 实际综合执行价 | $2,811.643279 / ETH |
| 相对参考价偏离 | +25.05085% |
| 不含 gas 的参考价差 | $2,000,768.95 |

参考行情是 Coinbase UTC 20:46:00–20:46:59 分钟收盘，严格使用已经完成的前一分钟，原始 candle 数组已归档。USDT 未按 $1 强制锚定。输出到账按钱包边界的实际 ETH/WETH 净变化计算；转账日志和原生 ETH 轨迹分别核算，gas 单列。该交易解码出 17 个 V2/V3 兼容池 Swap 事件，其多路路由顺序保留在 `decoded_swaps.parquet`。

计算为 `Input USD / ETH received`，并用 `Input USD - ETH received × Reference ETH/USD` 得到参考价差。价差包含可能的普通 AMM 冲击、费用、行情时点误差和 MEV 作用，不能称为套利者实际赚取 $2.00M。后续必须按机器人完整库存、gas、可识别付款和池前后状态另算 PnL。

## 4. 图 1 的解读

[交互图](figures/fig01_stolen_fund_flow.html)支持合约、UTC 时间、最低 USD 和缺失估值筛选；节点颜色区分来源交叉支持的钱包、仅有线索的钱包、报告中的 Binance 热钱包、Swap 事件发出合约和未知地址。节点大小及边宽使用当前显示边的 USD 规模。没有价格的边单独标为未估值。

[静态 PNG](figures/fig01_stolen_fund_flow.png)和 [SVG](figures/fig01_stolen_fund_flow.svg)展示 22 个选择后的事件（最大 18 个已估值转账及 4 个池路由事件，去重），完整事件哈希和数量见 `tables/fig01_static_edges.parquet`。图展示热钱包到接收钱包及池路由之间的交易联系；多跳边的合计是转手规模，不是新增被盗额或损失。

## 5. 限制与后续验证

仅 1,110 条边拥有当前严格 ETH/USDT/USDC 合约匹配和相应分钟行情。未知代币、缺失分钟和不同阶段收集的价格尚未统一，不作零值填补或 ticker 模糊匹配。

原始缓存已按 SHA-256 归档，原始采集时间缺失处明确为空。收据与缓存区块头一致性及调用树结构检查不提供独立共识链确认；本次没有声称已完成所有收据的密码学包含证明。

教师 PDF 中约 $2B 的措辞是被冻结的稳定币，不能写为不可追回的交易损失。最终对账将统一估值时间，分开资产存量、冻结/追回状态、实际兑换损失及 MEV 参与者内部转付。下一阶段先重建至少三个真实套利闭环，再关联相同区块拍卖交付和 proposer 转账。
